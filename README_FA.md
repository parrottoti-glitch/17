# راهنمای دریافت فایل APK و رفع تمام خطاهای بیلد

این پروژه شامل تمامی فایل‌های ضروری مانند `themes.xml`، `colors.xml`، آیکون‌های وکتور، تنظیمات گریدل و حالت تست اختصاصی است.

---

### روش اول: بیلد خودکار ابری با GitHub Actions (بدون نیاز به نرم‌افزار، ۲ دقیقه)
1. فایل زیپ را با دکمه **"دانلود فایل فشرده پروژه اندروید"** دریافت کنید.
2. وارد [GitHub.com](https://github.com) شوید و یک ریپازیتوری جدید (خالی) بسازید.
3. فایل‌های داخل زیپ را در ریپازیتوری آپلود کنید.
4. به تب **Actions** بروید. اکشن ساخت خودکار بدون نیاز به فایل اجرایی محلی با نسخه استاندارد گریدل ۸.۲ اجرا می‌شود.
5. پس از ۲ دقیقه، در بخش **Artifacts** روی **AutoClicker-Persian-Android10.apk** کلیک کرده و فایل آماده نصب را دریافت کنید!

---

### روش دوم: اجرا در Android Studio (کامپیوتر)
1. فایل زیپ را در پوشه‌ای Extract کنید.
2. در Android Studio گزینه **Open** را انتخاب کنید و پوشه استخراج شده را باز نمایید.
3. صبر کنید تا فرآیند **Gradle Sync** انجام شود (با استفاده از `gradle/wrapper/gradle-wrapper.properties` نسخه استاندارد گریدل دانلود می‌شود).
4. از منو: `Build -> Build Bundle(s) / APK(s) -> Build APK(s)` را بزنید.
5. فایل `app-debug.apk` در مسیر `app/build/outputs/apk/debug` آماده است.

---

### ویژگی‌های جدید اضافه شده:
1. **حالت تست آزمایشی (Test Mode):** دکمه زرد رنگ در برنامه که قبل از ساعت معین، ۵ کلیک آزمایشی روی نقطه هدف اجرا می‌کند تا از دقت مختصات و کارکرد سرویس مطمئن شوید.
2. **تنظیم تعداد کلیک‌ها:** فیلد و دکمه‌های سریع برای تعیین سقف کلیک‌ها (۴۰، ۱۰۰، ۵۰۰ کلیک یا ۰ برای حالت نامحدود).
